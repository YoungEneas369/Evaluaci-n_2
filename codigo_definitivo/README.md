# RutaSur: construcción paso a paso

Esta carpeta contiene únicamente el código que estamos construyendo desde cero, siguiendo el orden de las clases del profesor y adaptando los ejercicios a la agencia de viajes RutaSur. Es un trabajo en progreso, no la entrega completa.

## Estado actual

Completamos S6 hasta el ejercicio 9: propiedades de lectura e independencia entre objetos. Ya practicamos clases, atributos, constructor, creación de objetos, métodos que modifican datos y métodos que retornan resultados.

- `cliente.py`: datos del comprador, métodos para modificarlos y propiedades de lectura.
- `paquetesAgencia.py`: clase `PaqueteNacional` y cálculo del total por cantidad de viajeros.
- `main.py`: ejemplos de creación y uso de los objetos.

## Ejecutar

Con Python 3 instalado, abre una terminal dentro de esta carpeta y ejecuta:

```console
python main.py
```

Esta etapa no requiere instalar librerías externas.
